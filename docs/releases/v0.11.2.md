# v0.11.2 SQL repository safety

- Removed nine obsolete root-level SQL patches that were outside the canonical migration chain.
- Removed retired rules that could normalize explicit zero activity counts, expose orphan activities, restore physical activity deletion, or bypass current inventory RPCs if executed manually.
- Declared `supabase/migrations/` as the only authoritative database evolution path.
- Added repository safety tests that reject root-level executable SQL and retired activity access or repair rules.
- This release does not apply a database migration or modify production data.
