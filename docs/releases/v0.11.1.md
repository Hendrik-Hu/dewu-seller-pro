# v0.11.1 Trusted SKU entry

- Removed the demo SKU recognition control and its hard-coded third-party product data.
- SKU suggestions now come only from inventory already loaded for the signed-in seller and remain limited to five results.
- The legacy `lookup-sku` Edge Function remained as a compatibility endpoint at this release and returned no inferred or demo product metadata. It was removed in v0.20.1 after client usage reached zero.
- No inventory, product image, cost, or product name is changed by this compatibility endpoint.
