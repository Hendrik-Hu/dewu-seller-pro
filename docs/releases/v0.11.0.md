# v0.11.0 Warehouse integrity

## Seller-facing changes

- New accounts start with no fabricated warehouses. The first warehouse created becomes the default warehouse.
- Warehouse creation, default switching, renaming, and empty-warehouse deletion are atomic server operations.
- Warehouse names are unique after trimming and case normalization, with a maximum of six warehouses and one default warehouse.
- Warehouses with positive inventory cannot be deleted. Deleting a zero-stock warehouse does not create a data-health warning.
- Renaming a warehouse updates current product locations but preserves historical activity text.
- Manual and AI inbound both stop with clear guidance when no warehouse exists.
- Nonzero inventory referencing a missing warehouse is visible in Data Health and can only be repaired by choosing an existing warehouse with an audit reason.
