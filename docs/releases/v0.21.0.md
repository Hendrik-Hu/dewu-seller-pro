# v0.21.0 Android-only product entry

## Product surface

- Android APK/AAB is the only inventory-management product entry and continues to load the complete app from packaged local assets.
- Production Web no longer exposes inventory login, inventory data, statistics, AI, ledger or other seller workflows.
- The Web root accurately explains that the product is Android-only and that no public APK download is currently offered during closed testing.
- Dedicated Web support remains for email confirmation, password recovery, privacy, account-deletion guidance, a narrow authenticated account-deletion flow, support guidance and Android App Links.
- Local `npm run dev` remains a complete browser debugging surface.

## Build integrity

- `npm run build` produces the Web support target and fails if inventory business chunks or installable-Web metadata return.
- `npm run build:android` and every PowerShell Android build path explicitly produce the complete Android target.
- Production Web uses root-relative assets so `/auth/confirm`, `/auth/recovery` and `/auth/account-deletion` can load correctly; Android keeps relative assets for the Capacitor WebView.

## Distribution boundary

No public APK link is published because there is not yet a trusted public distribution channel with update provenance. Closed-test packages must continue to use the verified release signature and confirmed tester channels. A future download or update page must publish a signed artifact, checksum, version and upgrade policy from a user-owned HTTPS domain.

Public registration remains blocked on a user-owned domain and Custom SMTP. This version does not claim that closed-test email delivery is public-launch ready.
