# v0.22.0 Mobile Workflow Refresh

Release date: 2026-08-13

## Scope

- Reworked the Android home screen around the seller's daily sequence: review state, inbound, outbound, inventory lookup, and recent ledger activity.
- Reduced visual weight in inventory summaries and added a visible per-product management menu while retaining long-press access.
- Consolidated the statistics opening view around monthly sales, actual and estimated net profit, pending settlement, and settlement coverage.
- Reorganized profile tools into data and security, business settings, and account and support groups.
- Converted inbound and outbound into full-height mobile task surfaces with readable controls and reachable bottom actions.
- Added reusable mobile spacing, typography, surface, touch-target, form, task-layout, and safe-area tokens.

This milestone changes presentation and information hierarchy only. Inventory accounting, fees, settlement, RLS, transactional RPCs, operation IDs, drafts, backup and restore, and AI confirmation rules are unchanged.

## Boundaries and next milestone

- This remains an Android closed-test product. The hosted site remains a support surface rather than an inventory application.
- Public self-service registration and password email delivery still require a user-owned domain and custom SMTP before a public launch.
- The next product milestone is the sales-order lifecycle: sale creation, pending shipment, authentication outcome, return/reversal, and settlement without bypassing the existing ledger.
