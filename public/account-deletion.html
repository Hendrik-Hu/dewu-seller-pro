删除卖家库存助手账号

无需安装 App，可使用网页版完成
删除不可撤销。建议先导出完整 JSON 账本包，并单独保存重要商品图片。

网页版删除步骤

  1. 点击下方按钮进入网页版并登录账号。
  2. 进入“我的 → 账号安全 → 永久删除账号”。
  3. 阅读删除范围，输入“永久删除”和当前登录密码后确认。
进入网页版账号中心

删除范围

账号认证信息、库存及回收站商品、仓库、全部流水、费用方案、预计与实际结算记录、修复审计、恢复记录，以及该账号目录下的头像和商品图片。

处理时间与保留

页面显示删除成功后，账号登录状态会失效。对象存储与账号数据库属于两个处理阶段：若删除失败，账号和账本可能仍保留，部分媒体也可能已经删除；此时请保持登录并重试。我们不以可识别个人身份的形式继续保留已成功删除账号的业务数据；Supabase 等托管服务可能按其安全与可靠性策略保留必要日志。

删除异常联系

如果删除未完成，可在 GitHub Issues 反馈。请勿公开邮箱、订单号、库存明细、密码或访问令牌。
